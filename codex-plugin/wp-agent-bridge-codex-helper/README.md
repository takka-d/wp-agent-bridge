# WP Agent Bridge Codex Helper 0.1.0

This is an optional, skill-only helper plugin for Codex. It does not replace the WordPress-side WP Agent Bridge plugin and it does not contain credentials or an MCP server.

It makes Codex consistently follow the canonical user-owned GitHub Direct Runtime, current runtime capability catalog, guarded write flows, result observation rules, and connector-safe media upload workflow.

## Install

Import or upload `wp-agent-bridge-codex-helper-0.1.0.zip` as a plugin in a supported Codex/ChatGPT plugin environment. The exact UI can vary by plan, workspace, and surface.

After installation, the WordPress site still needs WP Agent Bridge configured separately, and Codex still needs access to the user's intended GitHub connection.
